# Inbox

`inbox/` 是零摩擦捕获区，用于尚未判断归属的想法、链接、截图、文献线索、会议记录和碎片材料。这里不是长期知识库。

捕获时至少记录日期、来源、潜在关联项目、保留理由和下一步。临时笔记使用 `YYYY-MM-DD-short-topic.md`。

每周清理一次：

- 文献与阅读证据进入 `literature/`；
- 可复用研究方法进入 `methods/`；
- 项目专属材料进入对应 `projects/<slug>/`；
- 通用且授权清楚的素材进入 `assets/`；
- 无法确认价值但需要保留的旧材料进入 `archive/`；
- 无保留价值且可再获取的内容可以删除。
