# Inbox

`inbox/` 是临时收集区，用于尚未整理的想法、链接、截图、待处理文献线索、会议记录和碎片材料。

## 使用规则

- 这里只放临时内容，不作为长期知识库。
- 每周至少清理一次，将内容移动或摘录到正式位置。
- 临时文件命名建议：`YYYY-MM-DD-short-topic.md`。
- 捕获时至少写明来源、可能关联的主题或项目、为什么值得保留、下一步处理方式。

## 整理去向

- 文献进入 `literature/`。
- 方法进入 `methods/`。
- 项目材料进入 `projects/<project-slug>/`。
- 通用素材进入 `assets/`。
- 暂无价值但可能以后有用的内容进入 `archive/`。
