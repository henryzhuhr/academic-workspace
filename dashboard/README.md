# Dashboard

`dashboard/` 是工作区总览和计划区，用于管理研究全局状态。

## 核心文件

- `README.md`：本说明和工作台入口。
- `projects.md`：所有项目索引、状态、负责人、下一步。
- `reading.md`：近期阅读队列和主题阅读计划。
- `weekly/`：周计划、周复盘、会议准备。
- `yearly/`：年度目标、季度规划、阶段总结。

## 维护规则

- 仪表盘只记录索引、状态和下一步，不承载详细研究内容。
- 项目的详细计划和材料放回对应 `projects/<project-slug>/`。
- 周报和复盘使用日期开头命名，例如 `2026-04-24-weekly-review.md`。
- 生成总结性报告时，从这里读取当前状态，但报告文件写入 `reports/`。
