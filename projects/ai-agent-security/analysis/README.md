# Analysis and Reproducibility

当前阶段是非计算型文献与框架综合，不运行数据分析或安全实验。证据通过以下路径追溯：

1. `literature/bibliography.bib` 保存引用条目。
2. `literature/reading-notes/` 保存单篇文献的主张、方法和限制。
3. `literature/topic-reviews/ai-agent-security.md` 保存跨文献综合。
4. 项目 README 保存当前理解，写作源稿保存展开论证。

后续若进入 benchmark 复现或攻击实验，必须先补充环境、数据版本、代码入口、参数、隔离边界和停止条件，并遵守 [工作区复现规范](../../../methods/reproducibility.md)。
