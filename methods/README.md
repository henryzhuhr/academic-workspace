# Methods

`methods/` 沉淀跨课题可复用的方法、协议和研究规范。与单个项目强绑定的做法先保留在项目中；经过验证并具有复用价值后再提炼到这里。

## 核心规范

- [data-management.md](data-management.md)：数据分类、存储、登记、不可变性和敏感材料处理。
- [reproducibility.md](reproducibility.md)：计算环境、输入输出、运行记录和最低复现要求。
- [arxiv-search.md](arxiv-search.md)：使用 arXiv 官方 API 检索、记录和筛选论文。

## 适合存放

- 阅读方法、编码规则、访谈协议、实验设计和统计流程。
- 写作规范、引用规范、投稿检查表和图表规范。
- 数据管理、伦理、隐私、版权和保密流程。
- 可复用的分析范式、命令说明和工具链配置。

方法文档应说明适用场景、输入、输出、步骤、限制和验证方式。涉及伦理、隐私、版权或保密的流程默认采取最保守处理。
