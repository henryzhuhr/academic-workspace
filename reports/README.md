# Reports

`reports/` 保存跨项目、跨主题、跨时间段或按需生成的总结性报告。项目本身的论文、汇报和交付物应留在 `projects/<slug>/outputs/`。

## 边界

- 项目专属源稿：`projects/<slug>/writing/`。
- 项目专属正式产物：`projects/<slug>/outputs/`。
- 跨项目或工作区级报告源稿：`reports/`。
- 报告导出的 PDF、DOCX 等成品：`reports/dist/`。

源稿命名建议使用 `YYYY-MM-DD-topic-purpose.md`，导出文件应包含日期或版本。

## 生成要求

- 明确报告范围、截止日期和读取过的关键来源。
- 结论能追溯到项目、文献、数据、分析或明确推理。
- 推断与事实分开；不确定内容标记“待验证”。
- 不得编造文献、DOI、作者、页码、数据来源或实验结果。
- 报告可以压缩源信息，但不能代替项目中的原始记录。
